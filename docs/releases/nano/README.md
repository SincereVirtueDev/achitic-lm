# AchiticLM Nano Release Docs

Status: READY_FOR_GITHUB_PUBLICATION

This folder documents the local Nano release package in `releases/nano/`.

- `MODEL_CARD.md`: model card and intended use.
- `ARTIFACT_MANIFEST.md`: artifact paths, sizes, checksums and provenance.
- `EVAL_REPORT.md`: smoke test evidence.
- `RELEASE_CHECKLIST.md`: publication checklist and blockers.
- `PUBLISH_INPUTS.md`: owner decisions needed before public GitHub release.

The package is ready for GitHub repository and release publication.
